# Spring AOP 

## 什么是**AOP**？与**OOP**的关系是什么？
AOP要比OOP更大一些，Java的面向对象准确来说是OOP，由于继承，子类可以任意重写父类方法。

这种树状结构有一个缺点，如果只想修改一段代码，就要重写父类的整个方法，显得格外冗余

于是乎，更为高级的AOP面向切片编程就诞生了！

## 什么是面向切面编程：AOP？

当然是为了解决刚刚说的问题。

## 什么原理？
采用*代理模式*，实现方式有两类：一种是父子(JDK 实现)、一种是兄弟(cglib 包)

简单来说，你写好的代码被Spring重写一遍作为代理，而被重写后得到的类要么是实现同一个接口的一个类，要么是原类的子类

得到的这个类再交给*Spring IoC*管理。

## 在Spring中如何使用呢？
在某个方法执行之前，之后，异常发生，都可以执行*增强类*中的方法。

使用AOP技术，就是在*增强*(*Advance*)原类。

增强类需要由`@Component`标记需要由*IoC*容器管理，并由`@Aspect`标记为这是一个增强类。

需要在XML配置文件中加入：
```xml
<aop:aspectj-autoproxy />
```
或者使用Java类配置

类中的方法，可以增添下面的注解：
| 注解 | 作用 |
| ---- | ---- |
| `@Before` | 在执行前 |
| `@After` | 在执行后 |
| `@AfterThrowing` | 发生异常时 |
| `@AfterReturning` | 正常返回时 |
| `@Around` | 环绕通知 |

`@AfterReturning`注解需要指定`value`切点，以及`returning` 形参名表示返回值，用`Object`接收
`@AfterThrowing`同上，但是要指定`throwing`并用`Throwable`接收

被注解修饰的方法可以有`JoinPoint`作为形参，获得目标信息


注解的参数是一串字符串，又命**切点**，格式为
`"execution(* <包名>.*.*(形式参数列表))"`

### 切点表达式
`"execution(1 2 3.4.5(6))"`
1. 访问修饰符
2. 方法返回参数类型
    空返回值写`void`

    如果不考虑访问修饰与返回值，两者可合成一起写`*`
3. 包的位置
    具体包、单层模糊（用`*`表示模糊匹配）、多层模糊（用`..`表示任意层）

4. 类的名称
5. 方法名 语法与类名一致
6. (6)形式参数列表
    无参：`()`
    有参：`(String)`，`(String,int)`
    模糊参数：`(..)`，`(String..int)`

#### 使用`@Pointcut`注解减少代码重复
1. 在当前类中声明一个切点
```java
// 在“增强类”中（@Aspect 修饰）

/**
 * 此处`pc()`即为切点
 */
@Pointcut(<切点表达式>)
public void pc() {}

// 通过`pc()`即可复用切点表达式
@Before("pc()")
public void before() {
    // 代理代码
}
```
2. 用单独的类储存切点

### 环绕通知 `@Around`
环绕通知可以代替前面提到过的四种，

用来修饰方法，形参为`ProceedingJoinPoint`，相对于`JoinPoint`来说，通过`proceed`方法手动调用


## 优先级
采用`@Order`注解为切点添加优先级，参数为`int`

**值越小，优先级越高**
